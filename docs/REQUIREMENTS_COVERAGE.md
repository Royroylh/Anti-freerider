# Requirements coverage

The [specification](SRS.md) defines 16 functional and four nonfunctional requirements for six user stories. The [design](DESIGN.md) identifies components D-01 through D-07. All 20 requirements have implementations. Each row names the checks performed and the verification limits. See [test coverage](TEST_COVERAGE.md) for the environment and counting method.

Suite keys: [API](../scripts/verify_e2e.py), [focused API](../scripts/verify_acceptance_fixes.py), [browser](../scripts/browser_walkthrough.py), [focused browser](../scripts/browser_acceptance_fixes.py), [unit](../server/test/af/RulesTest.java), [lifecycle](../scripts/verify_lifecycle.py) and [independent recomputation](../scripts/check_contributions.py). Bracketed numbers identify scenarios printed by the suites.
